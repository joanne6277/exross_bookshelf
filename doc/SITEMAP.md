## 彈出視窗 (Modals)

| Modal ID | 名稱 | 功能說明 |
|----------|------|---------|
| `book-info-modal` | 書籍詳情 | 顯示書籍資訊、立即閱讀、加入書單、封存 |
| `add-shelf-modal` | 加入書單 | 將書籍加入/移出自訂書單 |
| `add-collection-modal` | 新增書單 | 建立新的自訂書單 |
| `edit-collection-modal` | 編輯書單 | 重新命名或刪除書單 |
| `mobile-filter-modal` | 篩選與排序 (Mobile) | 手機版完整篩選設定 |
| `mobile-filter-sheet` | 篩選底部面板 | 手機版快速選項選單 |
| `share-note-modal` | 分享筆記 | 選擇引用格式、複製/匯出筆記內容 |
| `delete-note-modal` | 刪除確認 | 確認刪除筆記操作 |
| `issue-report-modal` | 問題回報 | 回報系統問題或書本問題、上傳截圖與聯絡方式 |
| `login-qr-modal` | QR Code 掃描 | 登入頁提供的載具綁定模擬視窗 |
